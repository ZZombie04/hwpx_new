장편 보고서 엔진

원고 한 장이
20쪽 보고서가 되기까지.

아래 그림은 모두 예시 원고(가상 학교 ‘가온중학교’)를 한글 2024 로 조판한 실제 쪽입니다. 다운로드한 폴더에서 같은 결과를 그대로 만들 수 있습니다.

STEP 1

예시를 복사해 내용만 바꿉니다

report init 이 바로 빌드되는 원고·자료(CSV)·사진을 만들어 줍니다. 구성과 표시는 그대로 두고 학교·주제·자료만 바꾸면 됩니다.

@ch Ⅴ | 결과 분석 | 세 연구 문제에 대한 답 | photos/ch5.jpg
@sec 2 | 연구 문제 ①: 교사의 수업 성찰은 높아졌는가
STEP 2

숫자는 AI 가 아니라 도구가 계산합니다

원고에 계산 명령을 쓰면 조판할 때마다 자료 파일에서 다시 계산해 본문에 넣습니다. 손으로 옮겨 적다 생기는 불일치가 사라집니다.

@stats paired data.csv --pre 사전 --post 사후 --prefix ref
평균은 {{ref.m0}}점에서 {{ref.m1}}점으로 올랐다
(t({{ref.df}}) = {{ref.t}}, p {{ref.p}}, d = {{ref.d}}).
STEP 3

차례 쪽수는 한글이 놓은 자리로

한글로 PDF 를 만들어 제목이 실제로 놓인 쪽을 읽고, 쪽이 바뀌지 않을 때까지 다시 조판합니다. 쪽을 넘는 표는 행 단위로 나누고 머리행을 반복합니다.

STEP 4

도표는 자료만 쓰면 같은 디자인으로

막대·묶음·효과 크기·산점도·누적·흐름·절차·순환 등 12종. 인쇄해도 읽히는 글자 크기와 300dpi 로 넣습니다.

@chart dose | 공개·참관 횟수와 성찰 변화 | type=scatter | data=data.csv | x=공개참관횟수 | y=성찰변화
@end
STEP 5

심사자가 먼저 짚을 실수를 미리

참고문헌에 없는 인용, 틀린 요일, 풀리지 않은 참조, 근거보다 큰 말, 검정 없는 ‘유의’, 쪽수 초과를 찾아 줍니다.

[오류] 참고문헌에 없는 인용: "홍길동, 2020"
[오류] 요일이 맞지 않음: 2026. 11. 5.(수) → 목요일
[주의] 근거보다 큰 말 "입증"
결과: 오류 0, 주의 0 ✓

설치

3분이면 준비됩니다.

Windows · macOS · Linux. 한글이 설치된 Windows 에서는 한글로 실제 PDF 를 만들고, 한글이 없으면 내장 렌더러가 근사 PDF 를 만듭니다(HWPX 는 같음).

파이썬 설치

3.9 이상. Windows 는 설치할 때 “Add python.exe to PATH” 체크.

hwpx_new 설치

git 이 없어도 됩니다. 압축 파일을 받아 install.bat 을 더블클릭해도 됩니다.

pip install https://github.com/ZZombie04/hwpx_new/archive/refs/heads/main.zip

자주 묻는 질문

한글이 없어도 되나요?

됩니다. HWPX 파일은 똑같이 만들어지고, PDF 는 내장 렌더러가 근사하게 만듭니다. 한글이 있는 Windows 에서는 한글이 직접 PDF 로 저장해 쪽 배치가 가장 정확합니다. 개발은 한글 2024 에서 실측했습니다.

어떤 AI 를 써야 하나요?

아무거나 됩니다. 모양은 도구가 정하고 AI 는 글만 쓰므로 모델에 따른 차이가 적습니다. 숫자는 @stats 계산 명령으로 도구가 계산하므로 가벼운 모델도 통계를 틀리지 않습니다. 가장 가벼운 모델(Claude Haiku)에게 지침만 주고 다른 학교·다른 자료로 맡겨 본 시험에서도 20쪽 보고서를 점검 오류 0 으로 완성했습니다.

통계를 몰라도 결과보고서를 쓸 수 있나요?

자료 파일(CSV·엑셀)의 열 이름만 알면 됩니다. 짝지은 t검정과 효과 크기 d, Welch t검정과 g, 신뢰도 α, 평정자 일치도 κ, 상관 r, 기술 통계, 비율을 계산하고 APA 표기(p < .001)로 본문에 넣습니다.

AI 가 숫자나 문헌을 지어내면요?

지침과 점검기가 막습니다. 수치는 계산 명령으로만, 인용은 참고문헌과 대조하고, 근거보다 큰 말과 검정 없는 ‘유의’를 경고합니다. 지어낸 내용이 있으면 최종 답변에 밝히도록 되어 있습니다.

제 서식(학교 양식)을 그대로 써야 하는데요.

그럴 때는 build 를 씁니다. 서식을 분석해 같은 모양을 복제하고 AI 는 글만 바꿉니다. 사용자가 한글에서 손본 파일은 patch 로 손본 곳을 지키며 고칩니다.
