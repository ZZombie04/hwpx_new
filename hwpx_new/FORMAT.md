# 내용 작성 형식 (Markdown 확장)

서식(HWPX)의 **모양은 자동으로 복제**됩니다. 여러분(AI)은 아래 문법으로 **내용만** 쓰면 됩니다.
빈 줄·간격·번호 모양·표 테두리는 서식에서 배운 대로 자동 적용되므로 신경 쓰지 않습니다.

| 쓰는 법 | 결과 |
|---|---|
| `# 문서 제목` | 표지/제목 블록 (문서에 1개) |
| `@subtitle 작성 부서` | 제목 아래 부제(부서명 등). 서식에 없으면 본문으로 처리 |
| `## Ⅰ. 소제목` | 소제목 바(번호는 직접 씀: `Ⅰ.` `1.` `가.` 등 서식과 같은 체계 사용) |
| `- 내용` | 글머리 문단(서식의 ●/○ 모양 자동). 들여쓰기 2칸 = 하위 단계 |
| `1. 내용` / `가. 내용` | 번호 문단 |
| 그냥 한 줄 | 일반 본문 문단 |
| `:::box 제목` … `:::` | 강조 박스(줄마다 한 문단). 제목 줄은 굵게 |
| GFM 표 | 표. 첫 줄이 머리글. 구분줄 `:-:` 가운데 / `:--` 왼쪽 / `--:` 오른쪽 정렬 |
| 셀 안 줄바꿈 | `<br>` |
| `<!-- widths: 1,3,2 -->` (표 바로 위) | 열 너비 비율 |
| `<!-- pagebreak -->` | 다음 블록을 새 쪽에서 시작 |
| `@end` | 공문 끝 표시 "끝." |
| `![캡션](사진경로)` (한 줄에 하나) | 단독 사진 + 가운데 캡션 |
| 한 줄에 `![](a.jpg) ![](b.jpg)` 여러 개 | 사진 격자(표) |
| `:::photos columns=3 title="제목" width_mm=50 max_height_mm=60` … `:::` | 사진 대지(표 안에 사진 격자 + 캡션 줄) |
| 표 셀 안의 `![설명](사진경로)` | 셀 안에 사진(설명은 사진 아래 글) |

## 병합 셀·정교한 표는 JSON

Markdown 은 셀 병합을 표현할 수 없으므로 필요하면 JSON 으로 씁니다.
`{"blocks": [ ... ]}` 형태이며 블록은 다음과 같습니다.

```json
{"blocks": [
  {"type": "title", "text": "문서 제목"},
  {"type": "subtitle", "text": "○○과"},
  {"type": "heading", "text": "Ⅰ. 개요", "page_break": false},
  {"type": "paragraph", "text": "본문"},
  {"type": "bullet", "text": "글머리", "level": 1},
  {"type": "numbered", "text": "1. 번호 문단"},
  {"type": "box", "title": "박스 제목", "lines": ["첫 줄", "둘째 줄"]},
  {"type": "table",
   "header": [[{"text": "기수", "rowspan": 2}, {"text": "강사", "colspan": 2}],
              [{"text": "주"}, {"text": "보조"}]],
   "rows": [["1기", "홍길동", "김철수"]],
   "widths": [1, 2, 2], "align": ["c", "l", "l"]},
  {"type": "clone", "from": 12, "texts": ["서식의 12번 블록을 복제하고 글만 바꿈"]},
  {"type": "image", "path": "사진/a.jpg", "caption": "단체 사진", "width_mm": 120},
  {"type": "gallery", "columns": 3, "title": "활동 사진",
   "images": [{"path": "사진/1.jpg", "caption": "준비운동"}, {"path": "사진/2.jpg", "caption": "릴레이"}]},
  {"type": "end"}
]}
```

- `header` 가 문자열 목록이면 머리글 1줄, 목록의 목록이면 여러 줄(병합 가능).
- 셀은 문자열 | `{"text":..., "colspan":n, "rowspan":n, "align":"c|l|r"}`.
- 제목 블록에 글 칸이 여러 개(기안문의 수신·제목·시행 칸 등)면 `{"type":"title","text":"...","fields":["칸1","칸2",...]}` 로 칸 순서대로 채운다(`analyze` 가 칸 목록을 보여 줌).
- `clone` 은 서식에 있는 특수 블록(결재란, 서명란 등)을 번호로 복제해 글만 바꿀 때 씁니다(`analyze` 결과의 [번호]).

## 사진

- 경로는 내용 파일이 있는 폴더 기준 상대 경로 또는 절대 경로. `hwpx-new photos 폴더` 로 사진을 미리 살펴본다.
- 자동 처리: EXIF 회전 보정, 긴 변 1600px 로 축소, HEIC/WEBP 등은 JPG/PNG 로 변환, 표시 크기는 칸 폭에 맞춰 비율 유지.
- 셀 안 사진의 최대 높이는 기본 70mm(`max_height_mm` 로 조정), 사진 대지는 60mm.

## 좋은 결과를 위한 요령

1. **서식의 뼈대를 따른다**: `analyze` / `scaffold` 결과의 소제목·표 구조를 기준으로 새 목적에 맞게 다시 쓴다.
2. 표 머리글의 열 수와 서식의 표 열 수는 같을 필요가 없다(자동 배분). 다만 한 줄에 너무 많은 열(7열↑)은 피한다.
3. 문장 어미·문체는 서식 원문과 통일한다(공문서는 개조식 `~함.` `~임.`, 안내문은 `~합니다.`).
4. 사용자가 주지 않은 사실(숫자·인명·날짜)을 지어 넣었다면 **반드시 최종 답변에 목록으로 알린다.**
