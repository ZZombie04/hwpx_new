# 장편 보고서 원고 문법 (`hwpx-new report`)

연구학교 결과보고서·연구보고서·논문형 보고서·사업 결과보고서처럼 **20~60쪽** 문서를 만든다. 서식 파일이 없어도 된다.
AI 는 **글과 표시(@…)만** 쓴다. 글꼴·크기·간격·표 테두리·번호·차례 쪽수·머리말·쪽 번호는 도구가 정한다.

```
hwpx-new report init 내보고서                 # 바로 빌드되는 예시 원고(report.txt)·자료(CSV)·사진 폴더를 만든다
hwpx-new report 내보고서/report.txt -o 결과   # → 결과/이름.hwpx + .pdf (차례 쪽수까지 맞춤, 1~3분)
hwpx-new report check 내보고서/report.txt --pdf 결과/이름.pdf   # 인용·참조·요일·쪽수 점검(오류 0 까지)
hwpx-new report prompt "요청" --data 자료.csv -o 프롬프트.txt    # 채팅형 AI(웹)에 붙여 넣을 글
```

## 1. 파일 구성 — 원고 하나(report.txt)

```
---
title: 첫째 줄|둘째 줄|셋째 줄          ← 표지 제목('|' 로 줄 나눔)
name: 2026_결과보고서_가온중            ← (선택) 결과 파일 이름. 없으면 제목
kicker: 2026학년도 연구학교 운영 결과 보고서
kicker2: 교육과정 교-6 | 시범 운영       ← (선택) 표지 작은 글
subtitle: 성찰–기록–소통으로 잇는 교원 성장
photo: photos/cover.jpg                  ← (선택) 표지 사진. 없으면 강조색 띠
info: 연구 기간 = 2026. 3. 1. ~ 2027. 2. 28.   ← 표지 정보 표(여러 줄)
info: 연구 대상 = 교사 32명, 학생 540명
date: 2026. 11.
org: 가온중학교
note: ※ 작성 예시: 수치는 가상 자료입니다.     ← (선택) 표지 맨 아래
header: 2026 연구학교 결과 보고서 · 가온중학교   ← (선택) 머리말 왼쪽 글
theme: wine        ← wine navy blue teal green forest plum brown charcoal red, 또는 accent: #RRGGBB
font: gothic       ← gothic(맑은 고딕) myungjo(휴먼명조+HY헤드라인M) nanum batang
page_limit: 50     ← (선택) 본문+참고문헌 쪽수 상한 점검
facts: facts.json  ← (선택) 숫자 토큰 파일(여러 번 가능)
---
@stats paired data.csv --pre 사전 --post 사후 --prefix ref   ← 통계 계산 명령(아래 4). 어디에 써도 됨
@front             ← 앞부분: 요약·일러두기(로마 숫자 쪽). 차례·표 차례는 자동으로 뒤에 붙음
@ftitle 연구 요약
@fsub 연구 문제별 주요 결과                    ← 앞부분 작은 제목
…
@body              ← 본문(장 Ⅰ~Ⅹ)과 참고문헌
@ch Ⅰ | …
…
@refs
…
@appendix          ← 부록(본문 쪽수에 넣지 않음)
@appx 부록 1. …
```

폴더로 나눠 쓰려면 `report.json` 에 같은 설정 + `"files": {"front": [...], "body": [...], "appendix": [...]}`.

## 2. 본문 표시

| 쓰는 법 | 결과 |
|---|---|
| `@ch Ⅰ \| 장 제목 \| 한 줄 설명 \| photos/a.jpg \| 요약1 ; 요약2 ; 요약3` | **장 표지 띠**(새 쪽, 강조색 칸 + 사진 + 요약 상자). 사진·요약은 비워도 됨 |
| `@sec 1 \| 절 제목` | 절 제목(두 색 밑줄, 차례에 들어감) |
| `@sub 가 \| 항 제목` / `@ssub 1) \| 목 제목` | 항 / 목 |
| 빈 줄로 나뉜 글 | 본문 문단(첫 줄 들여쓰기) |
| `○ 글` / `- 글` / `· 글` / `※ 글` / `⇒ 글` | 개조식 1~3단계 / 참고 / 결과 요약(굵게) |
| `**굵게**`, `^^강조색^^` | 글 안 강조 |
| `@table 키 \| 제목 \| widths=3,5,2 \| aligns=c,l,r \| size=s \| label_col \| split` 다음 줄부터 `\| 칸 \| 칸 \|` | 표(첫 행 = 머리행). `size=s` 작은 글씨, `label_col` 첫 열 강조, `split` 쪽 넘김 허용, `head=0` 머리행 없음, `unit=단위: 명`, `grid` 세로선 |
| 칸 안 `{b}` `{accent}` `{fill=#F6ECEF}` `{cs=2}` `{rs=3}` `{a=l}` + 글, 합친 자리 `<`(가로)·`^`(세로), 칸 안 줄바꿈 `⤶` | 굵게·강조색·칸 색·가로/세로 합치기·정렬 |
| `@tnote 주: …` | 표 아래 주 |
| `@chart 키 \| 제목 \| type=bar \| …` + 자료 줄 + `@end` | **도표 자동 생성**(아래 3) |
| `@fig 키 \| 그림.png \| 156 \| 제목` | 그림 파일(폭 mm) |
| `@photos 키 \| 제목 \| photos/a.jpg ; 설명 \| photos/b.jpg ; 설명` | 사진 1~4장 한 줄(`\| h=50` 으로 높이 mm, 한 장이면 틀이 사진에 맞춰 가운데) |
| `@box 제목 \| tone=accent` … `@end` | 상자(`tone=gray` 회색). 줄 앞 `○ ① ⇒ - ·` 는 단계 |
| `@voice 제목` … `@end` (줄: `인용 \| 출처`) | 인용(목소리) 상자 — 출처는 '도약기 교사 A' 처럼 가명 |
| `@kpi cols=4` … `@end` (줄: `값 \| 이름 \| 설명`) | 숫자 카드 |
| `@refs` / `@refh 1. 국내 논문` / `@r 참고문헌 한 편` | 참고문헌(새 쪽) |
| `@appx 부록 1. 제목` (`\| same` 은 새 쪽 없이) | 부록 제목 |
| `@page` | 새 쪽 |
| `// 메모` | 출력하지 않는 줄 |

**참조와 토큰**: 본문에서 `{표:키}` `{그림:키}` `{사진:키}` → '표 Ⅴ-3' 처럼 번호로. `{{이름}}` → `@stats` 결과, facts 파일, `@set 이름 = 값` 의 값.
`{{pages.body}}`·`{{pages.refs}}` 는 실제 본문·참고문헌 쪽수. 번호·괄호 뒤 조사(`{표:키}를`, `0.62였다`, `(교육부, 2024)는`)는 도구가 받침에 맞게 고친다.
`t(31) = 6.16`, `p < .001`, `[0.44, 0.88]` 같은 통계 표현은 줄 끝에서 갈라지지 않게 도구가 묶는다.

## 3. 도표 (`@chart`) — 자료만 쓰면 같은 디자인으로 그린다

```
@chart effect | 척도별 효과 크기 | type=effect
자기 성찰 인식 | {{ref.d}} | n=62 | 연구 문제 ①
다면평가 인식 | {{feed.d}} | n=62 | 연구 문제 ②
@end
```

| type | 자료 줄 | 쓰임 |
|---|---|---|
| `bar` / `hbar` | 이름 \| 값 | 월별 건수, 문항별 비율(`highlight=9월,10월`) |
| `group` | 이름 \| 값1 \| 값2 … (`3.18[2.9,3.4]` 신뢰구간) | 사전·사후 평균(`legend=사전,사후 min=1 max=5`) |
| `dumbbell` | 이름 \| 사전 \| 사후 [\| d 1.05] | 영역별 변화(`extra_label=효과 크기 d`) |
| `stack` | 이름 \| 비율1 \| 비율2 … | 응답 분포(`legend=1수준,2수준,3수준`) |
| `effect` | 이름 \| 값 [\| n=62 [\| 묶음]] | 효과 크기(0.2·0.5·0.8 기준선) |
| `hist` | 구간 \| 도수 | 변화량 분포 |
| `scatter` | x \| y | 산점도 + 회귀선 + r(`xlabel= ylabel=`) |
| `line` | x \| 값1 \| 값2 … | 꺾은선(첫 계열이 강조색) |
| `timeline` | 시기 \| 설명(줄바꿈 /) [\| 예정] | 정책·연혁 흐름(`highlight=3`) |
| `steps` | 단계 \| 시기 \| 설명(/) | 연구 절차 |
| `cycle` | 제목 \| 설명(/) | 순환 모형(`center=가운데 글`) |

공통 옵션: `label=도표 안 작은 제목`, `unit=`, `note=`, `min= max=`, `decimals=`, `width_mm=`. 축은 자르지 않는다(척도 1~5, 비율 0~100).

**자료 파일에서 바로 그리기**(자료 줄 없이 `@end`):

| 옵션 | 결과 | 예 |
|---|---|---|
| `data=자료.csv \| x=열 \| y=열[,열]` | 그대로(점·값) | 산점도 `x=공개참관횟수 \| y=성찰변화` |
| `data=… \| by=집단 \| y=열[,열]` | 집단별 평균(`order=초임,중견,원숙`, 이름 뒤 `(n=9)`) | 경력별 사전·사후 `type=group` |
| `data=… \| col=열 \| by=집단` | 집단별 비율(%) | 학기별 기록 수준 `type=stack` |
| `data=… \| col=열 \| bins=-0.5,0,0.5,1` | 도수분포 | 변화량 분포 `type=hist` |
| `where=열=값` | 일부 행만 | `where=학년=3` |

## 4. 통계는 도구가 계산한다 (숫자를 머릿속으로 만들지 않기)

원고에 **계산 명령**을 쓰면 조판할 때마다 자료 파일에서 다시 계산해 토큰이 된다(자료가 바뀌면 숫자도 같이 바뀜).

```
@stats paired data.csv --pre 성찰사전 --post 성찰사후 --prefix ref
→ {{ref.n}} {{ref.m0}} {{ref.s0}} {{ref.m1}} {{ref.s1}} {{ref.diff}} {{ref.t}} {{ref.df}} {{ref.p}} {{ref.d}} {{ref.ci}} {{ref.up}} {{ref.same}} {{ref.down}}
   본문: 평균은 {{ref.m0}}점에서 {{ref.m1}}점으로 올랐다(t({{ref.df}}) = {{ref.t}}, p {{ref.p}}, d = {{ref.d}}).
```

| 명령 | 토큰(접두 뒤) | 쓰임 |
|---|---|---|
| `paired 파일 --pre 열 --post 열` | n m0 s0 m1 s1 diff t df p d dav ci up same down upp r eff | 같은 사람 사전·사후(짝지은 t, d = 평균 변화 ÷ 변화의 SD) |
| `welch 파일 --a 값열 --group 시점열` (또는 `--b 열`) | n0 n1 m0 s0 m1 s1 diff t df p g d ci eff | 익명 설문처럼 독립 두 집단(Welch t, Hedges g) |
| `alpha 파일 --items 문1,문2,…` | alpha k n | 신뢰도 Cronbach α |
| `kappa 파일 --r1 열 --r2 열` | kappa agree n | 두 평정자 일치도(가중 κ, 완전 일치 %) |
| `corr 파일 --x 열 --y 열` | r p n df | 상관 |
| `desc 파일 --col 열` | n m sd median min max sum m1 | 평균·범위(예: 1인 평균 참여 횟수) |
| `freq 파일 --col 열 [--by 집단]` | `값`(%) `값.n`(명) n — 집단이 있으면 `집단.값` | 응답·수준 분포 |

모든 명령에 `--where 열=값`(일부 행), `--prefix 접두`. p 는 `< .001`·`= .023`(APA), 반올림은 사사오입. 미리 보기: `hwpx-new stats paired …`.
열 이름 자리에 `사후열-사전열` 을 쓰면 행마다 차이(변화량)를 계산한다: `@stats corr data.csv --x 독서량사후-독서량사전 --y 태도사후-태도사전`,
도표도 같다: `@chart … | type=hist | data=data.csv | col=태도사후-태도사전 | bins=-1,0,1,2`. α 가 .60 보다 낮으면 점검기가 알린다.
자료 파일은 CSV(UTF-8·CP949) 또는 XLSX. 학생 이름 없이, 교사는 매칭 코드로.

## 5. 좋은 보고서를 위한 규칙(점검기가 확인함)

- 연구 문제는 **질문** 3~4개, 결과 장의 절과 1:1. 결론에는 새 자료를 넣지 않는다.
- 결과 문단은 **주장 → 근거(n, M, SD, t, p, 효과 크기) → 해석** 순서. 산출(건수·참여율)을 효과로 말하지 않는다.
- '입증·획기적·완벽' 같은 근거보다 큰 말 금지, 검정 결과 없이 '유의' 금지. 기대와 다른 결과·한계·반대 사례도 쓴다.
- 인용 `(저자, 연도)` 는 참고문헌에 반드시 있고, 참고문헌은 모두 본문에서 인용한다. **실제로 있는 문헌만**(확인 못 하면 쓰지 않음).
- 표·그림·사진은 본문에서 `{표:키}` 처럼 한 번 이상 가리킨다. 날짜에 요일을 쓰면 맞아야 한다.
- 사진은 학생 얼굴·이름이 드러나지 않게, 지어낸 수치는 표지(note)·일러두기에 '가상 자료'라고 밝힌다.
- 빌드 결과의 `점검: 오류 0` 을 확인한 뒤 PDF 모든 쪽을 눈으로 본다(장 중간의 큰 빈칸, 칸에서 한두 글자 넘어감).
- 원고 실수(@end 빠짐, 모르는 표시, 칸 수가 틀린 표, 없는 사진 파일, 자료에 없는 열 이름)가 있어도 빌드는 멈추지 않는다.
  도구가 고칠 수 있는 것은 고치고 점검 결과에 `[주의]`·`[오류]` 로 알려 주므로, 그 목록대로 원고를 고쳐 다시 빌드한다.
